# pairwise-foot-ik

角色从斜坡走到台阶，前脚掌埋进地面，后脚又悬空，跑起来还一抽一抽：脚部 IK 只采脚底中心一点，斜坡前后高度差没采；骨盆高度按固定偏移，腿长和姿势变化后脚够不到；左右脚各自求解，互相拉扯；楼梯只用单射线，台阶边缘漏检；移动平台没把速度传给脚，角色在电梯上滑；根运动覆盖 IK，动画一播脚又穿地；膝盖翻转没限制，反向弯；速度过快时平滑跟不上，脚掌抖；网络只同步根节点，接触点不一致；地形法线没参与脚掌旋转，斜坡不贴面；脚部锁定事件在动画压缩后错位，落脚点漂；LOD 远端没有 IK，近处切换时脚跳；不同地面材质没有 IK 权重，冰面和泥地一样硬。gameplay/foot_ik.py 是核心，tests/test_foot_ik.py 15个红。要修的是：多点采样；骨盆求解；双足联合；台阶射线组；平台速度继承；根运动分层；膝盖限制；速度自适应；接触点同步；法线对齐；事件帧锁定；LOD 过渡；材质权重。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
